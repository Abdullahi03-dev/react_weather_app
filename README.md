# React Weather App

This is a weather application built with React and Vite, providing real-time weather updates for cities worldwide. The app is responsive, ensuring a smooth experience on both desktop and mobile devices.

## Features

- **Real-Time Weather Data**: Fetches current weather information for any city or country.
- **Responsive Design**: Built with React and Tailwind CSS for a smooth and user-friendly interface.
- **Fast Development**: Powered by Vite for fast hot-reloading and an efficient development experience.
- **ESLint Integration**: Ensures consistent code quality across the project.
